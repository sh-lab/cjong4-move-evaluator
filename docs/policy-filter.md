# 方策フィルター

方策フィルターは、cjong4が返した合法手をNN評価へ渡す前に絞り込む、または
評価値へ一定の補正を加えるC APIである。合法性そのものはcjong4が判断し、
フィルターはプレイヤーの個性や運用上の制約だけを担当する。

```text
cjong4の合法手
    -> ツモ・ロンの強制選択
    -> hardフィルターによる候補制限
    -> NN評価 + soft補正
    -> argmax
```

## 安全規則

- ツモ・ロンは他の設定より優先して選択する。
- hardフィルターで候補が空になった場合は、元の合法手へフォールバックする。
- 面前型が除外するのはチー・ポン・明槓であり、面前を維持する暗槓は残す。
- 向聴数は公開APIとPlayerViewだけから計算し、非公開情報を使用しない。
- 既存の評価APIは無設定のまま利用でき、従来と同じ選択結果になる。

## 設定

`cj4me_policy_filter_config`には、候補を除外するhard設定と、NN出力へ加算する
soft補正がある。

hard設定:

- `exclude_open_calls`: チー・ポン・明槓を除外する。
- `require_open_call`: 鳴ける局面ではPASSなどを除外し、鳴きだけを残す。
- `exclude_riichi`: リーチを除外する。
- `require_riichi`: リーチできる局面ではリーチだけを残す。
- `keep_best_shanten_discards`: 打牌・リーチ候補のうち、行動後の向聴数が最良の
  候補だけを残す。鳴き後の向聴数比較はまだ対象外である。
- `prefer_genbutsu_when_threatened`: 脅威となる相手がいる場合、その相手に対する
  現物の範囲が最大となる打牌候補だけを残す。現物が1枚もなければ除外しない。
- `prefer_kokushi_when_promising`: 国士無双の発動条件を満たす場合、国士向聴数が
  最良の打牌だけを残し、チー・ポン・各種槓と九種九牌を除外する。

soft補正:

- `open_call_bias`: チー・ポン・明槓へ加算する。
- `pass_with_call_bias`: 鳴き可能時のPASSへ加算する。
- `riichi_bias`: リーチへ加算する。
- `best_shanten_discard_bias`: 最良向聴数の打牌・リーチへ加算する。
- `safe_discard_bias`: 脅威相手に対する現物の割合に応じて打牌へ加算する。
- `kokushi_discard_bias`: 国士無双発動中、国士向聴数が最良の打牌へ加算し、
  国士を崩す行動から減算する。

float32評価では補正値をそのまま加算する。INT8評価では出力量子化スケールへ
変換して整数scoreへ加算するため、候補間のargmaxは整数演算のまま行う。

## プリセット

| プロファイル | hard | soft |
| --- | --- | --- |
| `standard` | なし | なし |
| `safe` | 脅威検出時に現物を優先 | 現物の脅威カバー率を加点 |
| `menzen` | 鳴きを除外 | 鳴きを減点 |
| `call` | 鳴ける場合は鳴きだけ | 鳴きを加点 |
| `speed` | 打牌候補を最良向聴数に制限 | 最良向聴数の打牌を加点 |
| `kokushi` | 有望時に国士を維持 | 国士を維持する行動を加点 |
| `riichi` | リーチ可能時はリーチだけ | リーチを加点 |
| `dama` | リーチを除外 | リーチを減点 |

`safe`は、相手のリーチ、相手がポン・明槓・加槓した役牌、または残り山40枚
以下で直近3捨て牌が連続ツモ切り、のいずれかを脅威として検出する。打牌候補の
牌種が脅威相手自身の捨て牌にあれば、その相手に対する現物として扱う。

`kokushi`は、現在の手牌に異なる么九牌が9種以上あり、国士向聴数が通常形・
七対子の最良向聴数から1以内なら発動する。条件外では標準方策として動作する。
国士無双の和了を個性報酬へ正確に反映するには、datasetへ和了役フラグを追加する。

## 自己対局CLI

```sh
./build/cj4me_generate \
  --games 100 \
  --seed 1 \
  --epsilon 0.1 \
  --model model-i8.cj4memodel \
  --policy menzen \
  --filter-mode soft \
  --filter-strength 0.05 \
  --output menzen.cj4medata
```

`--filter-mode hard`は候補を制限し、`soft`は候補を残して指定強度の補正を
加える。epsilonによるランダム探索はhard制限後の候補から選ぶが、soft補正は
モデルによる選択時だけ作用する。
